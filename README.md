# تطبيق إدارة التراخيص السحابي — Nexora License Admin (`almohaseb-admin`)

تطبيق الإدارة المستقل الخاص بمالك النظام للتحكم في اشتراكات وتراخيص تطبيقي **المحاسب (`almohaseb-v2`)** و**المحاسب بلاس (`almohaseb-plus`)** عبر قاعدة البيانات المشتركة (`nexora-broker`).

## المزايا الرئيسية
- تفعيل وتجديد وإدارة المنشآت والأجهزة المتصلة لكلا التطبيقين.
- لوحة مراقبة مساحة فيرباس (المساحة المستخدمة، المساحة المتبقية، وحجم النقل الشهري) بأسلوب الفحص الهجين الخفيف دون سحب `/workspaces.json` بالكامل.
- مركز التحكم السحابي: الإشعارات العامة والمجدولة، وضع الصيانة، فرض التحديث، ودعم الفني الذكي.
- بصمة تثبيت مستقلة (`com.nexora.almohaseb_admin`) مع التحديث المباشر داخل التطبيق عبر `/system/admin_version_manifest.json` ومرآة Fastly.
